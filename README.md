# ascendancydota.github.io

Developer homepage of AscendancyDotA (also the developer website for Google Play / Search Console).
Plain static HTML/CSS, no build step, no trackers, no external fonts – served by GitHub Pages.

- `index.html` (de), `en.html` (en), `impressum.html`, `datenschutz.html`
- Search Console: put the `google-site-verification` meta tag into the `<head>` of `index.html` (placeholder comment there).
- Own domain later: add a `CNAME` file with the domain and set it in Settings → Pages.
